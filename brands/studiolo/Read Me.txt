Studiolo 1.0
Private file tools that run in your browser.
Created by Daniel Velasquez · danvel1211@gmail.com

HOW TO OPEN
  Double-click Studiolo.html. Studiolo opens in your web browser.
  Nothing is installed, nothing is uploaded, and it works without
  an internet connection.

ADD STUDIOLO WITH ITS ICON (WINDOWS, OPTIONAL)
  Double-click "Add Studiolo to Desktop.cmd" once. It adds a Studiolo
  shortcut with the Studiolo icon to your Desktop and Start menu, and
  gives this folder the Studiolo icon. It doesn't install or download
  anything; you can open it in Notepad to see exactly what it does.
  If Windows asks whether to run it, choose "Run" (or "More info" >
  "Run anyway"). If you move the Studiolo folder, run it again.

  Studiolo.html itself shows your browser's icon: Windows uses the
  browser's icon for every .html file.

Keep the "resources" folder next to Studiolo.html. Studiolo needs it.

WHAT'S INSIDE
  File combination   merge PDFs and images, arrange pages
  Fill & sign PDF    fill forms and sign with a drawn, typed or uploaded signature
  Edit image         layers, filters, selections and object removal
  File converter     convert, inspect and resize images
